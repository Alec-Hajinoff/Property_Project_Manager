Property Project Manager is a lightweight workflow system designed for builders to manage building projects. Built with React (frontend), PHP (backend), and MySQL (database), the application helps builders oversee their pipeline of jobs while acting as the system of record for what was agreed, changed, approved, and delivered on each job.

Target User

The primary user of Property Project Manager is the builder or main contractor responsible for coordinating and delivering work on property projects, who needs a clear, defensible record of decisions and changes across multiple concurrent jobs, and who is the central user creating, managing, and overseeing all project data.

Value Proposition

Property Project Manager addresses the key challenges builders face when managing multiple projects simultaneously:

* Clarity and visibility: Builders can see the status of all active jobs at a glance, from enquiry to handover.
* Defensible records: Every agreement, change, approval, and key event is captured in a structured timeline, creating an auditable record that protects builders if disputes arise.
* Reduced ambiguity: By centralising decisions and approvals in one place, the application removes reliance on informal communication channels such as WhatsApp, email, or verbal agreements.

These capabilities combine to deliver confidence, accountability, and operational clarity - helping builders spend less time resolving misunderstandings and more time delivering work.

Core Features

Property Project Manager focuses on capturing and managing decision-critical project records for each property project, ensuring all essential information is documented and easily accessible:

Project Overview and Pipeline Visibility
* Dashboard view of all active and historical projects
* Track each job’s progress from enquiry through to handover

Project Record & Agreement Log
* Log project descriptions, specifications, and agreed terms
* Capture all changes, variations, and decisions as structured records
* Record explicit approvals, including who approved what and when
* Maintain a defensible record to support dispute avoidance

Materials and Evidence Tracking
* Record what materials were ordered and delivered
* Attach delivery confirmations, photos, or supporting evidence
* Log substitutions, delays, or exceptions as time-stamped events

Responsibility and Accountability Tracking
* Record who was responsible for each job stage and when responsibilities changed
* Log approvals from relevant parties for key decisions

Milestones, Events, and Timeline
* Capture major project milestones, site events, and change approvals
* Maintain a chronological timeline that shows how the project evolved over time

Why Builders Will Benefit

The application combines simple workflow visibility with rigorous record-keeping to give builders clarity, accountability, and control. By creating a single source of truth for decisions and changes, builders can reduce disputes, manage multiple projects with greater confidence, and protect themselves commercially - without trying to replace existing estimating, invoicing, or accounting tools, and without relying on fragmented spreadsheets, WhatsApp threads, or scattered paperwork.
